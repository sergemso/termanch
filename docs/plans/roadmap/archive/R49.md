# R49 Send a saved server to another device (share link)
Status: done (PR #110)
Score: V=9 T=8 R=3 S=2
Preds: none
Lane: free
Tier: archived
Was: new (owner request 2026-10-14)

Use case: the owner added a server on the iPhone (install command or QR) and wants the same server on a desktop browser. The server list is per browser (localStorage) until R18 syncs it, so the desktop shows nothing. The receiving half already existed (`#server=<id>` link, kept across the GitHub login, `addServerById` in `App.svelte`); the sending half did not.
Solution: a "Send to another device" button on each server card in `ServerList.svelte` (only for servers with a `server_id`). On an iPhone it opens the system share sheet (AirDrop to a Mac, Messages, Mail, Notes); elsewhere it copies the link and says to open it on the other device and sign in with the same GitHub account. The link carries only the public server id, never a secret; the server accepts only its owner (decision 0053), so the link is useless to anyone else. Code: `lib/share.ts` (`sendServerLink`), `lib/onboard.ts` (`serverLink`), tests `lib/share.test.ts`, `lib/onboard.test.ts`.
Not done here: sending all servers at once and settings is R18; a QR code on the phone would need the desktop to have a camera, so it was left out.
Done-when: tests pass; the owner confirms on the iPhone that the share sheet opens and that the desktop adds the server after login.
