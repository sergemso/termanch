Context: Decision 0109 (the terminal is first-class and super-convenient; the product aims for users not needing it). An ACP session has no native agent TUI, so this view is our own general TUI, not the agent's. Slash commands and modes come from `available_commands_update` and `current_mode_update`. Guardrails `soft-keyboard-never-hides-input`, `ui-never-moves-under-the-finger`.
Do: 1. A terminal-style view (xterm.js or a token-styled text surface, whichever scrolls, selects and copies best on iPhone) that renders the ACP stream: markdown messages, tool calls with kind and status, diffs, plan progress, and permission prompts inline with the same option buttons as the decision card (U.8). 2. A prompt line (send = `session/prompt`), interrupt on Esc and a visible button, slash-command completion and a mode switch from the agent's own lists, the key row, scrollback with search, copy, paste and dictation into the prompt, and the view keeps its place when switching sessions. 3. A companion shell: a plain tmux window in the session's working directory, one tap away, for real terminal work (ACP gives no user-typeable agent terminal). 4. A visible tier label "T0 · ACP". 5. Same components and tokens as the rest (0110).
Done-when: Playwright, against a fake ACP session, answers a permission from Home with one tap, interrupts a turn, searches scrollback, and restores the view after a reload; the terminal convenience checklist from decision 0109 passes on the owner's iPhone with the platform label.
