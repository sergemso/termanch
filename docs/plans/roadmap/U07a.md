Context: Agent Client Protocol is JSON-RPC 2.0 over stdio; the client starts the agent as a subprocess (spec pages: overview, session-setup, prompt-turn, tool-calls). A session therefore has no agent TUI, and a session the user already runs in tmux cannot be joined. `SessionBackend` is decision 0054; tiers are 0103; no standing rules is 0104; resource limits `resource-constraints`; untrusted text as 0095. Official SDKs include the Rust crate `agent-client-protocol`.
Do: 1. Decision drafted as 0111 (awaiting the owner); it also fixes the event model and quirk profiles. Original text: draft a decision amending 0103: a top tier T0 for ACP sessions that termenbox starts, observer sessions unchanged, and the owner's call on whether new sessions default to ACP when the agent supports it. Wait for the owner's acceptance before building. 2. An `AcpBackend` implementing `SessionBackend`: spawn the agent from a server-side allowlist of commands (config file; the client never supplies a command string), speak ACP over stdio (use the official crate if its size and licence fit, else a small client), `initialize` advertising minimal client capabilities (no file system, no terminal), `session/new` with the working directory. 3. Map `session/update` (`agent_message_chunk`, `agent_thought_chunk`, `tool_call`, `tool_call_update`, `plan`, `usage_update`, `session_info_update`, `current_mode_update`, `available_commands_update`) to additive wire messages old clients ignore; map `session/request_permission` to Attention with its options. 4. Show and accept only `allow_once` and `reject_once` (0104); answer with `{outcome: selected, optionId}` of exactly the option tapped; `session/cancel` for interrupt, answering pending permissions `cancelled`. 5. The server owns the child process, so client disconnects change nothing; on server restart use `session/load` or `session/resume` where the agent offers it, else mark the session ended. Bounded buffers, scrubbed, never audit-logged. 6. Measure RSS per agent and cap concurrent ACP sessions to fit 512 MB; an agent crash becomes state failed with its exit status.
Done-when: tests with a scripted fake ACP agent prove each update kind maps, a permission round trip selects exactly the tapped optionId, `allow_always` and `reject_always` are never offered, cancel resolves pending permissions as cancelled, a command outside the allowlist is refused, oversized or hostile text is capped and scrubbed, and a crash yields failed; the PR records RSS per measured agent.
